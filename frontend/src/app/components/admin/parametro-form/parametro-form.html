lightbulb_outline Como funciona a vigência

Cada parâmetro vale apenas dentro do seu período. Para mudar um valor a partir de uma data (ex.: novo teto do MEI em janeiro), cadastre um novo registro com a mesma chave e a nova vigência.

O sistema não aceita dois períodos que se sobreponham para a mesma chave — assim sempre há um único valor válido em cada dia.
